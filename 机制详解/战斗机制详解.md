# 苍屿战役 · 战斗机制详解（v4.18）

> 面向"想看懂整套战斗系统怎么转"的读者。所有数字都是引擎实值（`game/campaign.html`，v4.18 含机制补丁），
> 引用以函数名为准：`effStr` / `previewAttack` / `doAttack` / `terrainDefFor` / `ratioTier` 等，行号会漂移不写。
> 规则层的设计讨论见 `docs/20-机制设计合理性体检-v4.17.md`，战役级规则原文见 `docs/04-战役级规则.md`。

---

## 一、一次攻击的完整流水线

从你点下"开火"到战报写完，引擎按这个顺序走：

```
① 资格闸门（canFire / doAttack 三道闸）
② 算攻方有效战力（effStr + 协同 + 修正）
③ 算守方有效战力（effStr + 协同 + 防御叠放）
④ 比值 → 七档（ratioTier）→ 掷 D6 → 查 CRT
⑤ 结算双方战力损失 → 组织度跟着掉（每 1 点战力 = org −3）
⑥ 击退 / 退路堵死 / 突破跟进
```

**① 资格闸门**（任何一道不过，这一炮根本打不出去）：

| 闸门 | 规则 |
|---|---|
| 弹药 | 炮兵、海军弹药归零不能开火 |
| 展开 | 拖曳炮兵本回合移动过、或仍处于收拢状态，不能开火（要先展开） |
| 射程带 | `最小射程 ≤ 距离 ≤ 最大射程`。火炮有近界：旅炮 2 格起、师重炮 3 格起（榴弹炮打不了脚下的目标） |
| 无效接触 | 预估比值 < **0.35** 时拒绝开火（`INVALID_RATIO`）。最坏档的中位结果是"攻方掉 6、守方掉 2"，纯粹白送编制 |
| 崩溃 | 建制崩溃（`isBroken`）的部队列不出任何目标 |

目标列表（面板上的可选目标）与实际开火走的是**同一套闸门**——列表里没有的就是打不了，不存在"面板看不见但 AI 能打"的暗门。

## 二、有效战力（`effStr`）

一切战力的源头，三个因子相乘：

```
有效战力 = (基础战力 + 特性加成) × (组织度 / 100) ^ 1.30 × 补给系数
```

- **组织度曲线**（`ORG_CURVE = 1.30`）：不是线性打折。org 100 → 全力；org 50 → 只剩 41%；org 25（崩溃线）→ 只剩 16%。**越往下掉得越狠**，这是"连续作战三个回合的营失去进攻能力"的数学来源。
- **补给系数**（`SUPPLY_MOD`）：充足 ×1.00 / 紧张 ×0.82 / 断绝 ×0.58，详见第六节。
- 特性加成：如"为了祖国"（城心守军）直接加在基础战力上。

## 三、攻方结算

```
攻方 = (主攻有效战力 + Σ同格协同 × 0.50 + Σ相邻协同 × 0.35) × (1 + 攻击修正)
```

- **协同**：最多 3 支友军参与。与主攻**同格**的按 50% 计入（`STACK_COVER`），**相邻**的按 35%。集中兵力的收益远大于分散。
- **攻击修正**的来源：兵种相性（对空/对地/对海/对潜各有加成或惩罚）、单位特性、师旅光环等。
- **指挥部防炮**（v4.18）：攻方是炮兵或舰炮、守方是指挥部（HQ 单位）时，攻击修正 −0.30。指挥部的价值在光环与秩序，不该被炮火点名收割。
- **夹紧**（v4.17 补丁）：整支攻方战力乘数被夹在 **[0.15, 2.0]** 之间。没有下限，负面修正叠穿 ±1 会算出负战力；没有上限，修正池可以无限叠。

## 四、守方结算

```
守方 = (守方有效战力 + Σ同格协同 × 0.50 + Σ相邻协同 × 0.35) × (1 + 防御叠放)
```

防御叠放（`terrainDefFor`）从零往上加：

```
地形基础（平原 0 / 道路 0 / 机场 0.35 / 高地·港口 0.50 / 城区 0.85 …）
  + 自筑堑壕（fortify，最高 0.30）
  + 为了祖国 0.20
  + 单位特性（死战不退这类阵地底子）
  + 野战工事（碉堡 0.28 / 要塞炮 0.22 / 岸防炮 0.18 / 防空阵地 0.10）
```

两条硬规矩（都是 v4.17 补丁统一口径）：

1. **炮兵阵地暴露**：炮兵的一切被动防御收益**整体减半**——先是地形、再是堑壕、最后连碉堡一起打折。挪到公式最末尾统一乘 0.5，不再出现"同样掩体打折与否看谁修的"。
2. **夹紧 [0, 1.6]**：城区 0.85 + 自筑 0.30 + 碉堡 0.28 + 为了祖国 0.20 = 1.63，现有最大合法叠放已经贴着上限。1.6 封顶意味着防御乘数最多 ×2.6，不再有铁乌龟。

**多面进攻撕开死守**（v4.18）：攻方结算时，若**本回合已有另一格的敌军**打过这个守军格（`state.flanges` 记账：每个目标格记第一支进攻方的位置，回合边界清空），防御叠放整体 −0.30（`FLANK_PENALTY`，先扣再夹紧），战报会标"多面进攻（防御 −0.3）"。扎堆龟防的收益有了出口：敌人从两个方向压过来，堑壕就不那么可靠了。同格的第二支敌军不算多面（那还是同一个方向）；扣也只扣一次，不随方向数叠加。

另：空中单位不吃任何地形掩护（飞机蹲城里拿 +85% 是 bug 不是战术）；**同格的敌机**会被地面单位直接攻击（不打同格敌机就成了"和平共处"）。

## 五、比值、七档与 CRT

攻守两数相除得**比值**，按阈值切七档（`ratioTier`）：

| 档位 | 比值范围 |
|---|---|
| 3:1 | ≥ 3.0 |
| 2:1 | 2.0 – 3.0 |
| 1.5:1 | 1.4 – 2.0 |
| 1:1 | 0.9 – 1.4 |
| 1:1.5 | 0.65 – 0.9 |
| 1:2 | 0.4 – 0.65 |
| 1:3 | < 0.4（实际打不出：< 0.35 被无效接触闸拦下） |

每档掷一个 D6 查 CRT（`CRT[tier][d6] = [攻方损失, 守方损失]`，单位战力点）：

| 档位 | D6=1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| **3:1** | 0/4 | 0/5 | 1/5 | 0/6 | 1/6 | 1/7 |
| **2:1** | 1/3 | 0/4 | 1/4 | 1/5 | 2/5 | 2/6 |
| **1.5:1** | 2/3 | 1/3 | 1/4 | 2/4 | 3/5 | 3/5 |
| **1:1** | 3/2 | 2/2 | 2/3 | 3/3 | 4/4 | 4/4 |
| **1:1.5** | 4/1 | 3/2 | 3/2 | 4/3 | 5/3 | 5/3 |
| **1:2** | 5/1 | 4/1 | 4/2 | 5/2 | 6/2 | 6/3 |
| **1:3** | 6/0 | 5/1 | 5/1 | 6/2 | 7/2 | 7/2 |

读法：**3:1 打人几乎不疼自己，1:3 是自寻死路**。守方无法反击时攻方损失强制归零（打过壕沟里的坚守营不会被还手）。

**炮击覆盖整格**（v4.18，热补丁改为按兵力比例分摊）：上表查出的"守方损失"对炮兵是**面上损失**——目标格里所有敌方地面单位（`str > 0`、不含空中）**按各自当前战力比例**承担这笔损失（`splashSplit`）：
- **取整用最大余数法**：先按比例取下整，再把剩下的点数按小数部分从大到小补齐，**合计恒等于面上损失**。小数相同时给战力高的那支，仍平手按格内顺序（顺序必须定死：预览、实战、AI 评估各算一遍，规则一飘数值就对不上）。
- 例：伤害 4、战力 2 / 6 → 1 / 3；伤害 4、战力 3 / 7 → 1 / 3；伤害 3、战力 1 / 1 → 2 / 1（**不能四舍五入**，那会变成 2 + 2 = 4，比炮弹本身还多）。
- **下限（故意不守恒）**：被地形或工事削到 **2 点及以下**时，格内**每支各吃 1 点**。2 点炮弹落在三支残部中间会打出 3 点总伤——榴弹对密集队形的压制该有下限，"一支被打死、另一支毫发无伤"违反直觉。单支不吃这条（它本来就全吃）；伤害为 **0** 时全员 0（工事全吸收不能变成"必掉 1"）。
- 战报写"面上 −N（M 支按战力分摊 X / Y）"。每支受害者同时 org −3×份额、自筑堑壕清零。非炮兵路径不分摊（原行为：打谁就是谁）。堆叠协同照样给防御加成——挤一格防御更强，但一发炮弹也是按人头一起挨。

## 六、组织度与崩溃

| 事件 | org 变化 |
|---|---|
| 战斗每损失 1 点战力 | **−3**（损失与组织度是连动的：一次 4 点损失的齐射 = org −12） |
| 补给断绝 | 每回合 −10 |
| 整回合不移动不攻击 | +15（补给充足）/ +8（紧张） |
| 师部半径 3 / 旅部半径 2 光环内 | 额外 +10 |
| 被击退但退路堵死 | −8（`PUSH_BLOCK_ORG`） |
| 突破跟进成功 | −3（`BREAK_PUSH_ORG`） |

**崩溃机制**（拐点，不是线性惩罚）：

- 组织度跌到 **25** 以下 → 建制崩溃（`ORG_BREAK_DEF`）：本回合起**无法发起攻击**（两道闸：结算时刷新标记 + 开火前再拦一次），战报写明"建制崩溃"。
- 崩过的部队要回到 **40** 以上（`ORG_RALLY_DEF`）、且**脱离接触**（2 格内没有敌军）才能重新成军——被压着打的部队缓不过来。
- 例外：带"死战不退"特性的单位（如独立旅守备营）永不崩溃。

营级单位对这一条最敏感：9 战力的营挨一次 3 点损失 org 就掉到 91%，连打两三次就摸到崩溃线附近。

## 七、击退、堵死与突破跟进

击退成立需要**同时满足**：

1. 比值 ≥ **3:1**（最高档）；
2. 攻方是**中坦或重坦**（`canPushBack`）——轻坦没有吨位、步兵更不行；
3. 守军还有战力（打空了谈不上退）；
4. **沿击退方向逐格找得到空地**（一格能站两支，守军可能和友军同格；友军占着就不算空）。

结果分支：

- **找到退路** → 守军被推走，失去地形加成；随后**突破跟进**：攻方顺着缺口推进到守军原位（org −3）。一回合"移动一格 + 跟进一格"最多推进两格——"突破"在规则上由此成立。
- **退路堵死** → 守军挤作一团 org −8，谁也不动。
- 跟进前缺口会**重新判空**（守军走了友军还在 ≠ 缺口），地形与距离也会再判。

## 八、补给

按到本方补给源（陆上据点 BFS）的距离分三档：

| 距离 | 状态 | 战力系数 | 其他 |
|---|---|---|---|
| 半径 3 格内 | 充足 | ×1.00 | 可全额休整 |
| 4 – 6 格 | 紧张 | ×0.82 | 休整减半（+8） |
| 7 格以外 | 断绝 | ×0.58 | 每回合 org −10 |

特例：

- **辎重队**自持，永远充足；
- **舰船**按到码头/母港的距离；
- **航空兵**固定判"紧张"（×0.82）——敌境上空不吃地面补给场，但远离基地该收的那半笔照收。这是 v4.x 修过的暗坑：飞机以前落进地面补给逻辑，一出生就"断绝"。

补给与组织度是**相乘**的："断粮 + 疲惫"不是各减三成，是 0.58 × 0.25 ≈ 只剩一成半。

## 九、工事系统

一格可以同时有**一个掩体槽 + 一个火力槽 + 一个防空槽**的工事（v4.17 分槽规则，`FORT_SLOT`）；同槽替换只在新建工事的防御更高时成立。

| 代号 | 名称 | 防御 | 耐久 | 谁能修 | 特性 |
|---|---|---|---|---|---|
| H | 堑壕 | 0.15 | 无 | 步兵系自己挖 | 与自筑堑壕叠加 |
| B | 碉堡 | 0.28 | 3 | 工兵 | 装甲进攻此格额外 −0.15 |
| P | 要塞炮 | 0.22 | 5 | 工兵 | 驻守炮兵射程 +1；结算阶段自动打 3 格内敌军（2 点，不打相邻） |
| A | 岸防炮 | 0.18 | 4 | 工兵 | 封渡口：敌进相邻渡口 −2；结算阶段自动打 2 格内渡口/河岸敌军（3 点） |
| F | 防空阵地 | 0.10 | 3 | 工兵/防空连/防空营 | 压制敌机 + 驻军对空反击 |

分槽前的问题：工事按"防御值谁大谁留"裁决，防御 0.10 的防空阵地被 0.15 的堑壕**永久锁死**——想修 F 的格子先有 H 就永远修不了。分槽后掩体归掩体、火力归火力、防空归防空，互不遮挡。

## 十、防空与航空

三层对空，各管一件事：

| 层 | 来源 | 作用 |
|---|---|---|
| 削攻击 | 防空营（半径 4）+ 防空阵地 | 半径内敌机攻击修正 −0.35 / −0.25 |
| 压制 | 防空阵地 | 被压制的敌机每回合掉组织度，**下限 40**——高炮负责削弱，不负责把飞机打垮 |
| 反击 | 站在防空阵地上的地面单位（`aaBack` +0.55） | 遭空袭时还击，仅 1 格内（飞机扑到头顶才有效），不要求自带对空能力 |

航空兵自身的定位：攻击机对地 +0.60 / 对舰 −0.50（机炮打不穿装甲）；轰炸机是面压制；战斗机抢制空。飞机不吃地形掩护，也不用管"展开/收拢"。

## 十一、判分（简述）

三种胜利判定（关卡数据里的 `kind`），每种在"达成"之上还有一档**超额（perfect）**（v4.18 统一降难 + 教学关不留超额）：

- **score**：终局得分达到 `winScore` → 达成；达到更高的 `perfectScore` → 超额。得分来源包括要点控制、歼敌、撤出等。第六关两侧高地（lineW / lineE）各 10 分独立计——只守一条防线拿不满这 20 分。
- **reach**：撤出指定数量的部队（`escapeGoal`）→ 达成；超额看**战力留存 ≥ 初始的 60%**（幸存 + 已撤出之和 ÷ 初始战力，v4.18 从 0.7 降到 0.6——撤离关的战力本来就要付买路钱）。不看"多撤几支"：达标那一刻战斗就结束了，那条路走不到。
- **survive**：终局守住全部 `keep` 要点 → 达成；超额看**蓝方兵牌幸存数 ≥ 初始编成的七成**（`Math.ceil(initN * 0.7)`，v4.18 从"一个不损"放宽——炮兵面覆盖和多面进攻面前，"打得漂亮"和"零伤亡"是两回事）。

**教学关一律没有超额档**：`isTutorial()`（`ch === 0` 或 type 含"教学"）在 `judgeFinal` 和 `perfectHint` 两处同源分流——即便分数摸到超额线也按"达成"结算，菜单页也不显示「★ 可超额」。引导关的目标是让所有人能过，再挂更高的线只会把新手往"追求完美"上拽。

战术卡在**菜单页 →「更换战术卡」**（独立页面 `cards.html`）配置，跨关沿用；战斗内不再进 HQ 换卡，但 HQ 的其他功能（兵种图鉴、机制、副官、日志等）从战斗内**设置（齿轮）→ 战时手册**进。友军机制已预留：`side: 'ally'` 的兵牌按绿色渲染，尚未编入关卡。

平衡口径：普通关目标达成率 **45–60%**，"爽局"（如波尔瓦萨港）**65–90%**，教学关只要求能过。自战脚本 `tools/autoplay-campaign.js --diag` 可复测（含 org 触线、规则触发计数、得分直方图、工事落位矩阵四张报表）。
