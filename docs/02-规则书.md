# 苍屿战役 · 核心规则书 v0.1

> 本文是引擎实现的唯一依据。文档与代码不一致时，以本文为准，改代码不改文档算 bug。

## 一、单位属性

| 属性 | 含义 | 取值 |
|---|---|---|
| `str` | 当前战力点，≤0 即被歼灭 | 2–7 |
| `max` | 战力上限，用于战役级补充 | 同 str 初值 |
| `mov` | 机动点，每回合刷新 | 2–6 |
| `rng` | 射程（切比雪夫距离），0 表示无攻击能力 | 0–3 |
| `type` | 兵种：inf 步兵 / arm 装甲 / art 炮兵 / aa 防空 / eng 工兵 / fac 设施 | — |
| `dm` | 行动域：`ground` / `air` / `green` / `blue`。**单位上写了就覆盖兵种表默认值**，不写则取兵种表的 `dm`，再没有就是 `ground` | 四选一 |

**兵种特性（v0.1 只实现前两条）**
- 步兵：无地形额外加成（原设计的「城镇丘陵翻倍」已移除。城镇 0.75 翻倍到 1.5，等于战力按 2.5 倍算，攻方要凑 3:1 需 37 点战力，实战中不可能，等于城镇无敌）
- 工兵：`rng=0` 不能攻击；可修复跑道（v0.2）
- 装甲：平原机动无消耗惩罚，城镇移动消耗 +1
- 炮兵：不能移动后攻击（同回合）
- 设施：`mov=0`，永久驻留

## 二、地形与行动域

### 2.1 地形

地形有**两个机动坐标**，不是一套通吃的数字：

- `cost` —— 地面机动。`99` 表示地面部队根本进不去（水域、深水对步兵就是这样）。
- `nav` —— 水上机动。有这个字段才说明"这里能行船"，数字就是每格消耗。

刻意没有把河流的 `cost` 写成一个"看起来能走"的数字。布雷、筑垒、地形面板、
补给判定这些地面逻辑全都在读 `cost`，把水域改成低价会让它们悄悄把河当陆地用，
而且**不会报错**——这类 bug 只有玩家发现"工兵在河中间修了个碉堡"时才暴露。

| 字符 | 地形 | 地面消耗 `cost` | 水上消耗 `nav` | 防御加成 |
|---|---|---|---|---|
| `.` | 平原 | 2 | — | 0 |
| `f` | 林地 | 3 | — | +0.25 |
| `h` | 丘陵 | 3 | — | +0.50 |
| `t` | 城市 | 3 | — | +0.85 |
| `a` | 机场 | 2 | — | +0.35 |
| `#` | 道路 | 1 | — | 0 |
| `=` | 渡口 | 2 | — | +0.25 |
| `~` | 河流 | 不可通行 | 3 | 0 |
| `s` | 浅海 | 不可通行 | 3 | 0 |
| `d` | 深海 | 不可通行 | 2 | 0 |
| `p` | 港口码头 | 2 | — | +0.50 |

一格 = 2 km（港口关按 1 格 ≈ 1.5 km 计，见关卡简报）。

**舰船的补给不来自补给场，来自码头。** 水面格的 `cost` 是 99，补给场的 BFS 进不去，
所以海军单位不能按地面单位那套算——否则每条船一出生就判"断绝"，全员 −30%，
而战报上只会显示"断绝"两个字，看不出是规则漏了。现在的规则是：
泊位离**我方控制的码头格** 3 格内算充足、6 格内紧张、再远断绝。
码头被敌军占了就别想补给——"守港口"这件事因此有了明确的价格。

**补弹也按这个距离判，但不看这一回合打没打过。** 停泊（本回合没移动）且在
「充足」圈内，每回合 +1 发；一旦走出 3 格，补给降档，补弹立刻停。
舰炮的弹药是从岸上弹药库吊上来的，不需要"歇一回合"——这和拖曳火炮必须收炮转移
不是一回事。于是玩家的选择是"舰队靠港持续支援"还是"出港追歼、打完这轮没下轮"，
而不是"今晚算算术题"。

### 2.2 行动域

一支部队能走哪些格、和谁挤同一格、谁能打它——三件事同源，全由 `dm` 决定。
**加飞机、加军舰都只改兵种表一行 `dm`**，其余规则自动成立。

| 领域 | `dm` | 能走的地形 | 同格上限 | 谁能打它 |
|---|---|---|---|---|
| 地面 | `ground` | `cost < 99` 的地形 | 2 支（地表层） | 全部兵种 |
| 空中 | `air` | **任何地形，恒 1 点/格** | 1 支（空中层） | 仅 `aa:1` 的兵种与航空兵 |
| 绿水 | `green` | 河流 `~`、浅海 `s` | 1 支（地表层） | 全部兵种 |
| 蓝水 | `blue` | 浅海 `s`、深海 `d` | 1 支（地表层） | 全部兵种 |

四条配套规则：

1. **空中不受地形影响。** 什么地形都是 1 点，河流、深海、城市上空一视同仁。
   判定顺序是"先看领域、再看地形"——反过来写会让飞机被迫绕河飞。
2. **空中与水面是两层。** 飞机可以和满编地面部队停在同一格、互不占位，
   但空中层自己一格只放得下 1 支。水面单位（绿水 / 蓝水）和步兵同属地表层，
   本来就不该同格，所以共用一个上限。
3. **控制权 / ZOC / 工事 / 布雷只认地表单位。** 敌机飘在要点上空不改归属、
   不产生 ZOC；飞机自己也不受 ZOC。否则一架侦察机就能锁死一条走廊。
4. **空中不吃地形防御加成。** 城市 +0.85 是给躲在楼里的人，不是给飞在楼上的人。

水面**不能上岸**：绿水只能在内河与浅水活动，蓝水只能在外海与浅水活动，
两者都不进入任何 `cost < 99` 的陆地格。上岸必须靠登陆规则（尚未实现）。

## 三、回合流程

一回合 = 3 小时游戏内时间。

1. **我方阶段** — 每个单位可移动一次、攻击一次。攻击后本回合不可再移动。
2. **敌方阶段** — AI 依次执行移动与攻击。
3. **结算阶段** — 检查事件触发条件、占领判定、胜负判定。
4. 回合计数 +1，双方单位机动点与攻击状态刷新。

## 四、战斗裁决

### 4.1 有效战力

```
攻方有效 = Σ(参战单位 str) × 补给系数 × (1 + 支援加成)
守方有效 = 守方 str × 补给系数 × (1 + 地形防御)
```

v0.1 简化：单挑制，一次只判定一个攻方单位 vs 一个守方单位，不做多单位协同。

### 4.2 比值分档

`k = 攻方有效 / 守方有效`

| k | 档位 | 索引 |
|---|---|---|
| ≥ 3.0 | 3:1 | 0 |
| ≥ 2.0 | 2:1 | 1 |
| ≥ 1.4 | 1.5:1 | 2 |
| ≥ 0.9 | 1:1 | 3 |
| ≥ 0.65 | 1:1.5 | 4 |
| ≥ 0.4 | 1:2 | 5 |
| < 0.4 | 1:3 | 6 |

### 4.3 战斗结果表（CRT）

掷 D6，取对应列。值为 `[攻方损失, 守方损失]`，单位是战力点。

| 档位 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 3:1 | 0/1 | 0/2 | 0/2 | 1/2 | 0/3 | 1/3 |
| 2:1 | 1/1 | 0/1 | 0/2 | 1/2 | 1/3 | 2/3 |
| 1.5:1 | 1/0 | 1/1 | 0/1 | 1/2 | 2/2 | 1/3 |
| 1:1 | 1/1 | 1/2 | 1/1 | 2/2 | 2/1 | 2/2 |
| 1:1.5 | 2/0 | 2/1 | 2/1 | 2/2 | 3/2 | 2/3 |
| 1:2 | 3/0 | 2/1 | 3/1 | 3/2 | 4/1 | 3/2 |
| 1:3 | 3/0 | 3/0 | 4/1 | 4/1 | 5/2 | 4/2 |

### 4.4 占领

守方单位被歼灭且攻方为敌方时，攻方自动进入该格（若机动允许）。单位站在 `a`（跑道）格上即视为控制该格。

## 五、补给

v0.1 只做三档状态，不做逐单位路径演算。

| 状态 | 系数 | 触发条件 |
|---|---|---|
| 充足 | 1.0 | 默认 |
| 紧张 | 0.8 | 油库被敌方控制 |
| 断绝 | 0.5 | 油库失守且敌方控制 ≥ 2 格跑道 |

## 六、季节

关卡开始时预报，整关生效。

| 季节 | 机动 | 侦察 | 补给消耗 |
|---|---|---|---|
| 春 | −1 | 0 | +1 |
| 夏 | 0 | 0 | 0 |
| 秋 | 0 | +1 | 0 |
| 冬 | −1 | −1 | −1 |

动机修正作用于所有单位 `mov`，最低不低于 1。

## 七、胜利条件

每关三段式，直接决定调参目标：

- **失败**：核心目标失守（关卡单独定义）
- **达成**：核心目标保住
- **超额**：达成 + 附加条件（通常是对敌损失比例）

自战脚本按「达成率」调参，目标区间 45–60%。

## 八、事件系统

```
{ id, when:{ turnAbove | unitLost | hexCaptured | strBelow }, effects:[...] }
```

效果作用域三层：

| 层级 | 字段 | 作用 |
|---|---|---|
| 战术 | `tactical` | 改本关剩余回合的修正 |
| 战役 | `campaign` | 写入战役状态，影响下一关初始条件 |
| 战略 | `strategic` | 改幕间资源 |

**硬约束**：每个事件必须存在玩家可执行的规避手段，且触发前有可见预兆。

## 九、v0.1 实现范围

已实现：地形移动、单挑裁决、CRT、占领、三档补给、季节、战术级事件、AI 启发式。

未实现（留到 v0.2）：工兵修复、多单位协同攻击、战争迷雾、战役状态存续、支援加成、侧翼判定。

# 附录 B · 谁能打谁（目标分类）

目标分类和行动域是两件事。潜艇在水面上机动（域 = 蓝水），但它的目标分类是 **`sub`**，
所以没有对潜装备的军舰打不了它——这一点决定了海战怎么打。

| 类别 | 谁属于这一类 | 说明 |
|---|---|---|
| `air` | 战斗机 / 攻击机 / 轰炸机 / 运输机 | 只有 `aa` 兵种与航空兵打得着 |
| `land` | 全部地面部队 | 最常见的目标 |
| `ship` | 内河炮艇 / 鱼雷艇 / 护卫舰 / 驱逐舰 / 巡洋舰 / 战列舰 / 航母 / 运输舰 | 水面舰艇 |
| `sub` | 潜艇 | 需要专门的对潜能力 |

**主动攻击白名单**（兵种表的 `atk`）——不在名单里的类别，界面上根本列不出来：

| 兵种 | 可主动打 | 打不了 |
|---|---|---|
| 战斗机 | 空中、地面 | 水面、潜艇 |
| 攻击机 | 地面、水面、空中（弱） | 潜艇 |
| 轰炸机 | 地面、水面 | **空中（仅可对空反击）**、潜艇 |
| 鱼雷艇 | 水面 | **地面（仅可反击）**、空中 |
| 潜艇 | 水面 | 地面、空中、潜艇 |
| 战列舰 | 地面、水面 | **潜艇**、空中（只有弱防空） |
| 驱逐舰 / 巡洋舰 | 地面、水面、潜艇 | 空中（只有防空） |

**反击是另一套规则**：`atk` 只限制"主动挑谁打"。被攻击时能不能还手，由射程与近界决定，
不看 `atk`——所以轰炸机挨战斗机咬时能还手（自卫机枪），鱼雷艇挨岸炮打时也能还手。
