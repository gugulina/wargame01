# 33 · 游戏设计总评与推进路线图（v5.3）

> 评审日期：2026-11-16　视角：**游戏设计师**（不是代码审计）
> 数据来源：引擎实测（`tools/load.js` 载入）、自战 40 局/关、素材清单、现有 32 份设计文档
> 一句话：**战术层已经是一套能打的兵棋，但它现在还不是"一个战役"，而且它在告诉玩家"我还没做完"。**

---

## 零、一句话诊断

| 维度 | 判断 |
|---|---|
| 战术手感 | **好**。CRT 不对称、组织度崩溃与收拢、补给、夜战射界、5 种工事、41 兵种——这套东西有味道，玩家能感到"集中兵力"的收益 |
| 内容完成度 | **27%**。67 个关卡条目里 18 个能玩，首页上 49 个灰条在喊"未完成" |
| 元循环 | **缺失**。关与关之间零决策，18 关是 18 个独立谜题，不是一条战役 |
| 难度曲线 | **失控**。18 关里 11 关在 45–60% 目标带外（1 关 12.5%，4 关 100%） |
| 表达 | **偏薄**。2 张立绘对 20 个说话人；兵牌是纯文字；地图是 CSS 色块 |
| 可回访性 | **几乎为零**。无评分、无成就、无沙盘、无难度档，通关即结束 |

## 一、它现在是什么（事实盘）

### 1.1 规模

| 项 | 数值 |

| 已实装关卡 | **18**（序章 1 + 第 1 章 9 + 第 2 章 8，含 5 个附属关） |
| 关卡条目总数 | **67**（未实装 49，占 73%） |
| 回合数 | 7–20，平均 **11.9** |
| 地图 | 12×9 → 22×16（1.5 km/格，全图最大 33×24 km） |
| 兵种 | **41** 种（步兵 6、装甲 3、炮兵 5、工兵 2、反坦克 2、防空 2、侦察 1、航空 4、海军 8、后勤/指挥 5、特殊 3） |
| 工事 | 5 种（堑壕 / 碉堡 / 要塞炮 / 岸防炮 / 防空阵地） |
| 地形 | 12 种 |
| 战术卡 | **6** 张，每局带 3 张，跨关沿用 |
| 胜利条件 | survive **9** · reach **3** · score **3** · demolish 1 · escort 1（另有教学关 1，走 score 分支） |

### 1.2 单局时长（估算）

12 回合 × 每回合 1–2 分钟 ≈ **15–25 分钟/关**；全战役 **6–8 小时**。
这是一个"周末能通关"的体量——对独立兵棋刚好，对"战役"偏短。

### 1.3 表现层

| 项 | 数值 | 判断 |
|---|---|---|
| BGM | 5 首（menu / battle / tension / win / lose，2.3 MB） | 够用，但不分章节 |
| 音效 | 33 个（0.9 MB，含合成与实录音） | 够用 |
| 立绘 | **2 张**（旅长 / 103 师长），另有 2 张母版 | **明显不足** |
| 剧情文本 | 231 段 `text:`、**95 条对白**、**49 个说话人**、11 处剧情卡 | 文本量足，表现跟不上 |
| 兵牌 | 34×28 文字块（番号 + 战力 + 组织度条 + 编成色带） | 信息密度高，**辨识度低** |

## 二、玩家实际会怎么体验它

### 前 10 分钟：很好

T1 教学关用 6 条"演习科目"把移动、攻击、火炮、工事、占领、组织度点了一遍，打完给 10 分。
**这是全项目做得最成熟的部分**——按顺序点按钮就能学会，不需要读手册。

### 第 1 小时：开始出现"这游戏有点东西"的瞬间

C1 北岭要塞：8 回合、两翼防线、核心要点丢了就判负。玩家第一次感受到
"我不能把兵摊开，必须集中"——因为 CRT 在 3:1 时交换比是 11:1（见 docs/32 §2.1）。
这一关 60% 达成率，是**全项目最接近设计意图的难度**。

### 第 3 小时：疲劳开始

打到 C5/C6/C7，玩家会发现：**目标又双叒是"坚守 N 回合"**（9/18 关都是）。
变的是地图和兵力，不变的是"别丢要点、熬到回合结束"。
这时候玩家想要的不是新机制，而是**一个理由去在乎这些关**——也就是战役层，而它不存在。

### 第 5 小时：两个挫败点会赶走一部分人

- **C2（12.5%）**：突围关，要求 14 支里撤出 4 支。自战平均只撤出 1.95 支。玩家会卡在这里，而且**没有任何提示告诉他为什么**。
- **C4B（15%）**：要求撤出 10/17，是全部关卡里需求比例最高的（59%，其他两关 29%/33%）。

### 通关后：没有下一个理由

18 关打完 → 结局 → 回首页。没有评分、没有成就、没有难度二周目、没有沙盘。
**这个游戏对玩家的"剩余价值"是 0**——不是内容少，是没有钩子。

## 三、八个缺漏（按对体验的伤害排序）

### 缺漏 1 🔴 没有战役层：18 关是"关卡集"，不是"战役"

**现象**：打完一关回首页，下一关开局是**固定编制、固定兵力、固定卡组**。玩家在关与关之间唯一的动作是"点下一关"。

**证据**：
- `campaign.html` 全文 0 处战役层代码；跨关状态只有战术卡（`:8647` "牌组存在战役进度里，跨关沿用"）。
- 引擎里对"跨关传递"有一次明确的拒绝：C8 注释（`:4267-4269`）写"不引入跨关状态……收益不抵风险"。**这个判断在当时是对的**（存档字段 + 判定复杂度），但它把"战役"这件事整个放弃了。

**为什么是问题**：战棋的长期乐趣不在单场战斗，而在**编成与取舍**——哪支部队活下来、把补充兵给谁、下一关带什么。现在这些决策全被数据表替玩家做了。18 关打完，玩家记住的是"18 个谜题"，不是"我带的那个师"。

**建议**：做**轻战役层**（不要做重型养成）：
1. **战役点数**：每关按达成/超额给 1–3 点，跨关累计；
2. **关间三选一**：花 1 点买"补充兵 +2 张兵牌" / "预置工事" / "额外战术卡位"；
3. **部队延续（可选开关）**：上一关存活兵牌按 70% 战力带入下一关，全灭则重置为该关默认编制。
4. 数据模型：`progress.meta = { pts, roster: {levelId: {unitId: str}}, buffs: [] }`，写进现有 `wargame.lankao.save` 旁边的独立 key，坏档只影响战役层、不影响关卡解锁。

**验收**：连续打 3 关的玩家，能说出"我为什么这样选"至少 1 次；战役层存档损坏时，关卡仍可正常进入。

### 缺漏 2 🔴 首页 49 个灰条：系统在告诉玩家"我没做完"

**现象**：菜单页把 67 个关卡条目全列出来，其中 49 个是"制作中 / 未解锁"。

**证据**：`index.html:651` `if (!lv.ready) return { ok: false, why: '制作中' }`；`:778` 渲染成 `state.wip`。

**为什么是问题**：玩家对"完成度"的判断来自**第一屏**。第一屏就有 73% 的灰条，等于在封面上写"半成品"。而且灰条点不动，是纯负面交互。

**建议**（三选一，按成本排序）：
1. **默认只显示已实装**（18 关），章节头写"本章 9 / 9 关已开放"；未实装章节折叠成一行"第 3 章 · 制作中"（成本：1 小时）；
2. 把未实装关改成"**战役预告**"样式（暗色 + 一行悬念文案，不可点），至少提供叙事价值（成本：半天）；
3. 真的把 49 关做出来（成本：**不现实**，见 §四）。

**验收**：新玩家第一次进首页，看不到任何一个"制作中"标签。

### 缺漏 3 🔴 难度只有一个档，且基线脱靶

**现象**：没有难度选择；18 关里 11 关在 45–60% 目标带外（C2 12.5%、C4B 15%、C7 27.5%、C8 35% 太难；C2B/C3B/C4 100% 太简单）。

**为什么是问题**：这不是"某关数值不对"，而是**方差结构问题**——难度差异主要来自关卡设计，而不是玩家成长。新手在 C2 撞墙、老手在 C4 无感，两头都留不住。

**建议**：两条独立的轴，别混在一起：
- **难度档**（`剧情 / 标准 / 硬核`）：只调三样——红方初始兵力 ±20%、波次提前/延后 1 回合、`minAlive` 判定线。**不碰 CRT 与 AI 参数**（那是所有关共用的地基，一动全乱）。
- **关卡基线修正**：按 docs/32 §2.6 的清单把 11 关拉回带内（`minAlive` 四关 + C2/C2B/C4B 的 `count`），这是"让标准档真的等于标准"。

**验收**：标准档下 18 关全部落在 40–65%；剧情档下最难的 3 关 ≥70%。

### 缺漏 4 🟠 目标同质：9/18 关都是"坚守 N 回合"

**现象**：survive 9 关、reach 3 关、score 3 关、demolish 1、escort 1。中段 5 关连续是"守到回合结束"。

**为什么是问题**：兵棋的乐趣来自**目标差异**（守住 / 打穿 / 抢时间 / 保人）。连续同类型会让玩家把每关当成"同一道题的变体"。

**建议**：
1. **次要目标**（可选、影响评分不影响胜负）：保桥、保车队、保某支兵牌、在 N 回合前拿下某点。现有 `objectives` 结构已支持多要点，只需加一层 `optional` 标记与结算展示。
2. **把 2–3 个 survive 改造成混合目标**：例如 C6「守 14 回合 **或** 在 10 回合内打掉敌指挥部」——两种打法，不同风险。
3. 新关优先补 reach / escort / demolish 的比例（第 3 章如果要做，类型配比建议 4:3:2:1）。

**验收**：连打 5 关，玩家不会连续遇到 3 关相同目标类型。

### 缺漏 5 🟠 输了不知道为什么：没有失败反馈

**现象**：失败只弹结算面板（战果 + 兵力对比），没有"哪条线破了、哪支先崩、下次先做什么"。

**为什么是问题**：这类兵棋的学习曲线全靠"复盘"。没有复盘，玩家只会觉得"这关太难"，而不是"我这步走错了"。C2/C4B 的低达成率有一部分就是**信息问题**，不是难度问题。

**建议**：结算面板加一个"复盘"折叠区，三行以内，全部从现有 state 现算：
1. **第一条被突破的线**：哪个要点先易手、第几回合；
2. **最早崩溃的部队**：哪支、第几回合、当时组织度；
3. **如果重来**：一句针对本局数据的建议（"你在 X 方向投入了 6 支，Y 方向只有 2 支"）。
成本约 1 天，因为 `state.log` 与 `objectives` 已经记录了这些事件。

**验收**：失败后玩家能复述"我是在第几回合丢了什么"。

### 缺漏 6 🟠 卡池太薄，局外 build 不存在

**现象**：6 张卡（强行军 / 坚守 / 集中突击 / 炮火准备 / 急造工事 / 空投补给），每局带 3 张，跨关沿用。

**为什么是问题**：3/6 的选择不构成 build，"带哪三张"很快就会收敛成固定解。而卡是**唯一**跨关的决策——它本可以承担"战役层"的部分职能。

**建议**：
1. 扩到 **15–18 张**，按章节解锁（第 1 章 8 张、第 2 章 +10）；
2. 加入**代价型卡**（"透支：本回合全部部队 +1 机动，下回合组织度 −15"），让选择有取舍；
3. 卡与关卡联动：突围关推荐机动卡、坚守关推荐工事卡——推荐不强制，但要在开局提示。

**验收**：自战或测试中，至少出现 3 种不同的"最优三张组合"。

### 缺漏 7 🟡 表现层：兵牌认不出兵种，立绘只有 2 张

**现象**：兵牌 34×28，只有 2–3 个汉字（"中坦""重坦""反""工"）。新人分不清；老玩家也要靠详情栏。**立绘 2 张，对 49 个说话人、95 条对白。**

**建议**：
1. **兵牌加 NATO 军兵种符号**（步兵 ×、装甲椭圆、炮兵实心点、工兵桥、骑兵斜线、航空机翼），10×10 像素即可，配兵种色。这是兵棋的"通用语言"，成本低、辨识度提升最大。
2. **立绘走"无线电/简报"路线而不是"人人有脸"**：现在 11 处剧情卡，其中 2 个说话人有立绘，其余用"无线电字幕条"样式（无头像也成立），比硬凑 20 张立绘省得多、也更符合"师部电台"的叙事口吻。
3. 如果一定要补：按"每章 3 个关键人物"补，第 1 章 3 张、第 2 章 3 张，共 6 张。

**验收**：不看详情栏，能在 2 秒内说出任意兵牌的兵种。

### 缺漏 8 🟡 通关之后没有下一个理由

**现象**：无评分、无成就、无沙盘、无难度二周目。

**建议**（按性价比排序）：
1. **关卡评分 S/A/B**：用现有数据（回合数、损失、超额达成）算，写入 `progress`，首页显示。成本 1 天。
2. **通关解锁"沙盘模式"**：用已实装 18 张地图 + 自由编成（双方兵力可调），成本 3–5 天，寿命延长最大。
3. **战役勋章**（全 S / 零损失通关某关 / 单关不败）：成本 2 天。
4. 排行榜不做（需要后端，与本项目的纯静态定位冲突）。

**验收**：通关玩家中有工具记录的回访行为（重打某一关 / 打开沙盘）。

## 四、不该做的事（先说砍什么）

| 不做 | 理由 |
|---|---|
| **补完 49 关** | 18 关已经是 6–8 小时。补完是 3 倍工作量、且会稀释质量。第 3 章最多再加 8–10 关就够讲完故事 |
| **加战争迷雾** | docs/18 设计过，但现有 18 关的难度全是"全图可见"下标定的。加迷雾等于重做全部关卡 |
| **做多人对战** | 纯静态、`file://` 可跑是这项目的最大优势（双击即玩）。联机要服务器，收益远小于成本 |
| **做 3D / 换引擎** | 六角格 + CSS 的表现已经够用，换引擎只会把 6,700 行测试与 32 份文档全部作废 |
| **补 20 张立绘** | 成本高、收益低。走"无线电字幕"路线更贴合叙事 |
| **做云存档** | 隐私 + 后端成本；现有"导出 JSON"已经能满足换机需求 |

## 五、路线图：三个里程碑

### M1 ·「像个做完的游戏」（2–3 周）

| 交付 | 具体内容 | 验收 |
|---|---|---|
| 首页收口 | 默认只显示 18 关；未实装章节折叠成一行预告 | 新玩家首页 0 个"制作中"标签 |
| 难度两档 | 剧情 / 标准（硬核延后）；只调兵力与判定线 | 标准档 18 关 40–65%；剧情档最难 3 关 ≥70% |
| 战绩复盘 | 结算面板加"三行复盘" | 失败后玩家能说出第几回合丢了什么 |
| 兵牌符号 | NATO 军兵种符号 + 兵种色 | 2 秒辨识测试通过 |
| 卡池 6 → 12 | 新 6 张含 2 张代价型 | 出现 ≥3 种不同最优组合 |

**为什么先做这个**：M1 全是"低风险、高感知"的改动，不需要新机制，也不动战斗内核。做完之后，游戏第一次"看起来是完整的"。

### M2 ·「让 18 关变成一条战役」（3–4 周）

| 交付 | 具体内容 | 验收 |
|---|---|---|
| 战役点数 | 达成 1 点 / 超额 2 点，跨关累计 | 存档往返不丢点 |
| 关间三选一 | 补充兵 / 预置工事 / 卡位 | 连打 3 关至少做 1 次有意义的选择 |
| 部队延续（可选） | 存活兵牌 70% 战力带入，全灭重置 | 开关默认关；开启时坏档不影响解锁 |
| 关卡评分 | S/A/B，写入进度，首页显示 | 评分与本局回合/损失一致 |
| 次要目标 | `optional` 标记 + 结算展示 | 至少 6 关有可选目标 |

**为什么第二**：战役层是"从关卡集到战役"的唯一分界线，但它需要 M1 的评分与难度基线打底，否则会放大脱靶的难度。

### M3 ·「能发布」（3–4 周）

| 交付 | 具体内容 | 验收 |
|---|---|---|
| 沙盘模式 | 18 张地图自由编成 | 通关玩家能随手开一局 |
| 表现补强 | 6 张立绘或无线电演出；2–3 首章节 BGM | 剧情卡不再"无脸" |
| 真机验收 | Android 上过一遍：音频、后台、存档、横竖屏 | 三条真机问题清单清零 |
| 商店素材 | 5 张截图 + 1 段 30 秒录屏 + 文案 | 可提交 |
| 成就 | 8–12 个 | 至少 1 个由"重打旧关"触发 |

## 六、如果只做三件事

按投入产出比，我会只做这三件：

1. **首页收口**（1 小时）——把"我还没做完"从第一屏删掉。这是全项目最便宜的信任修复。
2. **难度两档 + 4 关 `minAlive` 修正**（3 天）——让"标准"真的等于标准；新手不再在 C2 撞墙。
3. **轻战役层（只做点数 + 关间三选一）**（1 周）——把 18 个谜题变成一条线。不做部队延续也能成立，它是"最小可用的战役"。

这三件做完，游戏的"完成度感知"会有质变，而战斗内核一行不用改。

## 七、风险与取舍

| 风险 | 说明 | 缓解 |
|---|---|---|
| **战役层把存档搞复杂** | C8 注释拒绝过跨关状态，理由成立（字段多、判定多、坏档面大） | 战役层独立 key；坏了只丢战役层；每关仍可单独进 |
| **难度档改变平衡结论** | 一旦有难度档，现有 45–60% 目标就要按档重定 | 先定"标准档=现状+"，只改兵力与判定线，不碰 CRT |
| **兵牌加符号会挤** | 34×28 已经很满（番号 + 战力 + 组织度条 + 色带） | 符号占左侧 8×8，番号缩到 2 字；先做 3 个兵种试点 |
| **49 关不做但留着占位** | 玩家会一直看到"未完成" | 这就是 M1 第一件事要解决的 |
| **内容量 vs 质量** | 18 关每关都经过 40 局自战 + 体检 | 第 3 章建议只做 8 关，宁可少而稳 |
