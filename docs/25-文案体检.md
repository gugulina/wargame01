# 文案体检：把"AI 味"去掉

> 体检对象：`game/campaign.html` 里玩家能看到的全部文字，约 1.5 万汉字（清单见 `docs/24-游戏文案总表.md`）。
> 本文只记**判定标准**与**改法**，不重抄文案——要读原文看 docs/24。

## 结论

文案的问题不是"写得不好"，是**通篇只有一种声音**：同一个人、同一种节奏、同一个句式，从序章讲到第八章。
信息是准的，规则是对的，但读起来像一份被润色过的说明书。

一轮改完，六个指标里五个动了，一个没动（段落等长，见第五节）：

| 指标 | 改前 | 改后 |
|---|---|---|
| 破折号（处 / 千字） | 8.1 | **0.5** |
| 设计者视角（「这一关」「第 N 章的收尾」） | 14 | **2**（都是世界内的说法） |
| 简报标题对偶（「X，Y」） | 13 / 30 | **8 / 30** |
| 「不是 A，是 B」句式 | 9 | 4 |
| 段落变异系数（越接近 0 越等长） | 0.29 | 0.29（**没改善**） |
| 段落最长 / 最短（字） | 64 / 18 | 60 / 14 |
| 汉字总数 | 15,754 | 14,949 |

## 一、六个病灶

### 1. 破折号解释句（最要命的一条）

中文正常写作破折号约 1–3 处 / 千字。改前是 8.1，接近三倍。表现是**每给一个结论，后面必挂一句补充说明**：

> 南北两翼各有一道堑壕，但都只有一人深——挡得住散兵，挡不住装甲。
> 走进撤离区的部队立即离场，不占格、不再参战——所以不要指望它们掩护后面的人。

单看每一句都通顺，连读三页就成了同一个腔调：作者不信任读者，怕你没听懂。

**改法**：断成两句，或者让信息自己站住。改后全篇只剩 0.5 处 / 千字。
（残留的几处是"两段防线是两个口袋，破一个，另一个就成了突出部"这类真需要转折的地方。）

### 2. 反转警句癖

> 这一次，输了不会有人死｜封锁线是死的，钳子是活的｜跑道是最不该站人的地方｜往南跑，别往东跑｜用阵地换兵力

一句两句是锋利，三十句连排就是同一张嘴在抖机灵。而且这类句式有个副作用：**标题比内容响**，玩家记住了对仗，没记住任务。

**改法**：标题一半换成具体物象或命令。

> 混凝土是这里唯一充裕的东西 → **一人深**
> 圈还有四十公里宽 → **两把钳子**
> 撑够八个回合 → **八回合**
> 舰炮能打到的地方，步兵就不必硬顶 → **七条船**

### 3. 设计者视角混入

最破坏沉浸的一类。玩家在 1207 年的要塞里，突然有人探出头来讲关卡设计：

> **这一关**只是让你把按钮点一遍。
> **这一关**教的不是"找路"，是"什么时候走"。
> **第 2 章的收尾**。城还在，但城外已经没有一支援军了。

**改法**：全删。六处「第 N 章的收尾」一个不留——那是给作者看的目录注，不是给玩家看的。

### 4. 教练腔

> 别把跑道当禁区——敌军压上来，就得拿预备队把它顶回去。
> **把预备队留到那时候。**

教学关里合理（教官在讲话），正关里就是把玩家的决策替他想完了。

**改法**：正关保留"情报"，删掉"建议"。把"别把跑道当禁区"改成"跑道不能空着"，陈述代替指挥。

> 注：量化表里"别…"从 31 变到 32，看着没降。这是统计口径的问题——它抓的是所有"别"字，
> 分不出"别恋战"（人物在喊）和"别把新兵摆在公路上"（作者在教）。后者已经基本清完。

### 5. 段落等长（唯一没解决的）

改前 90 段简报正文，标准差 9.8、均值 34.2，变异系数 0.29——**每段都是 30–40 字，每页都是三段**。
这是 PPT 提纲的节奏，不是人写东西的节奏。

改后 0.29，没动。原因见第五节。

### 6. 人物没有毛病

28 段 `beats` 加 85 条事件对白，说话的人有师长、旅长、营长、工兵、舰长、敌方无线电台——**语气是同一个人**。

改法：给每个说话人一个毛病，并且只用一次。

| 人物 | 毛病 | 落地 |
|---|---|---|
| 第 103 步兵师师长（C1） | 行政脑，按编制想问题 | 「两个团归我。地图上我还按三个团画的。」 |
| 第 1 边防旅旅长（C1） | 报数，心疼弹药 | 「炮弹四十发，一发一发数着用。」 |
| 第 201 坦克旅旅长（C2） | 自负，看不起步兵 | 「步兵跟得上就行——跟不上，那是他们的事。」 |
| 工兵连连长（C2B / C5） | 只谈手里的活 | 「我蹲在桥底下补。上面过车，下面掉木屑。」 |
| 机场守备营营长（C3B） | 有私心，舍不得 | 「我在这机场守了九年，不能让它断在我手里。」 |
| 第 301 预备役师师长（C6） | 护犊子 | 「挖工事挖得慢，枪打得歪，听见炮响会趴下。可他们是我的人。」 |
| 敌台（各关） | 电报体，没有主语 | 「要塞有守军。工事完好，没炸开。」 |

"有人情味"落到具体手法上只有一条：**让命令里夹一句跟战斗无关的事**——师长记着地图上的编制、
工兵记着头顶掉木屑、营长记着九年。不写"他心里难过"，写他在数什么。

## 二、六条改写纪律

写新关卡、改老文案，按这六条走：

1. **破折号每千字不超过 3 处**。超了就是解释句成瘾。
2. **标题不许连续两页用对偶**。三页里最多一条「X，Y」。
3. **不许出现"这一关 / 这一局 / 第 N 章的收尾"**。设计者视角只在 docs 里出现。
4. **正关只给情报，不给建议**。「敌军第 7 回合到」是情报，「把高炮摆在码头」是建议。
5. **一页里至少有一句短的**（十来个字），**至少有一句长的**（五十字以上）。
6. **同一关里两个说话人不许用同一种句式**。

配套两条硬约束（docs/08 §8.7），改稿时不能破：

- `teaser` / `name` / `when` / `where` 是**纯文本拼接**，不能写 `**加粗**` 或 HTML；
  `briefing` 正文、`intro`、`abil`、事件 `text` 走 `bold()`，可以写。
- 改机动 / 弹药 / 修正值，必须回头改 `TYPE[].abil` 里的格数。

## 四、顺手修掉的一个真 bug

C4B「港口撤离」的达成线在某一版从 6 支改成 10 支，`win.count`、正文、态势说明都改了，
**标题和数字条没改**——玩家看到的是「六支，不到六支就是失败」，数字条写「6 支撤出」，
但实际要 10 支才过关。

改稿时一并改成「十支，一支都不能少」，数字条写「10 支撤出」。

**这类过期文案只有对着规则读才看得出来**，`npm test` 不管：断言的文案一律从数据里取，
不在测试里抄一遍（`briefcheck` 的注释写着为什么）。所以改数值之后，得人工核一遍同页的文字与数字条。

## 五、没解决的一项：段落等长

变异系数改前改后都是 0.29。原因有两个，都不完全是文案的错：

1. **版式把它锁死了**。简报是固定三页，每页 3–4 段，一段在纸面上就是两三行。
   想让某段只有一句，视觉上会空一块——改到第三关我就放弃了硬凑长短。
2. **大部分段落真的是一组并列信息**（编制、工事、敌军波次），拆成长短不齐反而不像公文。

真正该打破等长的是**对白**（`beats`），而那一块已经改了——现在每关三句里至少有一句是短的
（「守多久？」「船没了，人跑不掉。」）。量化表只统计简报正文，所以看不出来。

## 七、战报体：把推演数据行改成战况通报

第二遍改的是**打的过程中滚出来的那一栏**（`state.log`）。这部分不在 docs/24 里，
因为它是 57 处模板拼出来的，不是数据里写死的文案——所以单独记。

### 改前长这样

```
1-1 边防第 1 旅第 1 营 机动至 K5
1-2 攻击 14侦（平原 · 1.5:1 · 骰 1 · 协同 3）→ 我方 -2，敌方 -3 · 多面进攻（防御 −0.3）
  14侦 敌第 14 步兵师装甲侦察营（轻坦） 被歼灭。
```

三个毛病，都不是"文笔"问题：

1. **简称和全名并列**。地图上印的是 `1-1`，战报里却写"1-1 边防第 1 旅第 1 营"，一行三十多字，
   八回合下来满屏都是番号全称，读的人立刻改看地图。
2. **词是规则表的词**。`骰`是桌游词，参谋部不会在通报里写它；`支`、`格`、`战力`同理。
3. **没有时间轴**。八回合的战报连成一片，玩家分不清哪条属于哪一轮。

### 七条规矩

| # | 规矩 | 例子 |
|---|---|---|
| 1 | 主语只用简称，全名留给检视面板 | `1-2 进至 K5` |
| 2 | 动词用军语 | 机动至 → 进至；来不及 → 不能；被歼灭 → 被歼 |
| 3 | 计数用「部」，位置用「处」 | `该处已有 2 部` |
| 4 | 不写「战力」二字，直接给数字差 | `我 −2，敌 −3` |
| 5 | 零伤亡不写 −0 | `我无损，敌 −3` |
| 6 | 判定点叫「判」，不叫「骰」 | `判 1` |
| 7 | 一条通报一行：主语 攻 目标（地形·兵力比·判·协）：我损，敌损 | 见下 |

### 改后

```
—— 第 3 回合 ——
1-2 进至 K5
14-1 攻 1H（城市 · 1.5:1 · 判 1）：我无损，敌 −3，对方未能还手
  1H 被歼。
◆ 敌军判断兵力占优，转入追击
```

**保留的四样**：兵力比（`1.5:1`）、判定点数（`判 1`）、协同数（`协 3`）、炮兵面覆盖的分摊
（`面上 −3（2 部分担 1 / 2）`）。这些是玩家拿来推下一次决策的，删了战报就成了纯文学；
而且正式战报也不会只说"打得很惨"，总要有数字。

**清掉的**：`兵牌`（玩家可见文本里一处不剩）、`支`、`单位`、`骰`、`战力`、简称与全名并列。

### 「兵牌」清到了哪些地方

不是只有战报栏。凡是玩家能读到的地方都换了，因为简报和态势**本身就会滚进战报**：

| 位置 | 改前 | 改后 |
|---|---|---|
| 简报数字条（9 关） | `兵牌 12` | `部队 12` |
| 完美条件 | `兵牌幸存不少于七成` | `部队幸存不少于七成` |
| 任务说明（16 处） | `全部兵牌被歼立即判负` | `全军被歼即判负` |
| 结算面板 | `幸存兵牌 5 支` | `尚有战力 5 部` |
| 检视面板分组标题 | `兵牌能力` | `部队能力` |
| 序章教官七条 | `点兵牌选中` | `点部队选中` |
| 视觉标记 | `兵牌带斜纹 / 兵牌上出现红边` | `图标带斜纹 / 图标上出现红边` |

斜纹和红边确实画在那个方块上而不是部队身上，所以这几处改的是「图标」，不是「部队」。

### 顺带补的时间轴

`endTurn` 的回调里本来就有一行回合横幅，但**开局那一次不走回调**，于是第一回合的二十来条
战报一直挂在抬头的「前情」「态势」下面。现在 `newGame` 结尾补了一行 `—— 第 1 回合 ——`。

### 断言跟着改

改文案必须同步改断言，否则测试红在"文案变了"而不是"行为错了"：

| 断言 | 旧判据 | 新判据 |
|---|---|---|
| 炮击战报给出逐支份额 | `/面上 -(\d+)（(\d+) 支按战力分摊/` | `/面上 −(\d+)（(\d+) 部分担/` |
| 战报写明「对方无法反击」 | `indexOf('对方无法反击')` | `indexOf('对方未能还手')` |
| 端到端 runAI 开火 ×2 | `indexOf('攻击')` | `indexOf(' 攻 ')` |
| 特殊单位排在…之前（briefcheck） | `indexOf('兵牌能力')` | `indexOf('部队能力')` |

最后一条按纪律**反向验证**过：把分组标题改回「兵牌能力」，断言当场报红，确认它测的是渲染结果而不是自己。
