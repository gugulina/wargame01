## 一、开战：借口、目标、时点

### 事实

| 事实 | 出处 |
|---|---|
| 灰原以「边境事故」为由，秋季发动突袭；苍屿北部边防 72 小时崩溃 | `docs/01:13-14` |
| 灰原联合体是北方的**资源型联邦**，陆军规模占优，擅长炮兵与摩步协同 | `docs/01:10` |
| 灰原的战略目标：夺取长湾海峡**北岸**的岚口机场群，建立前进航空基地 | `docs/01:11` |
| 岚口是北部唯一可起降运输机的机场，全战役核心 | `docs/01:22` |
| 苍屿东临长湾海峡，**重装备依赖进口**；波尔瓦萨是南部唯一深水港 | `docs/01:7`、`docs/01:75` |
| 苍屿常备军规模有限，主力为守备旅编制 | `docs/01:7` |

### 【补】把三件事接成一条链

1. 灰原要的不是一块土地，是**长湾海峡的通道**。苍屿的重装备全靠海运进口，
   海峡一被掐，进口就断；北岸机场是掐通道的支点，不是终点。
2. 所以「边境事故」是制造既成事实的**借口**：先把边防打崩，再沿两条线取通道的两端——
   西线正面压北岭（C1），南线绕开主力直取唯一深水港波尔瓦萨（C4）。
   **C1 与 C4 不是敌人忽然换了个方向，是同一个目标的两只手。**
   `README.md:79` 只写了"第 4 关是南线的分岔"，没写为什么；这条因果把分岔接回主线。
3. 两端必须成对拿到：只拿机场，海运仍可从南岸走；只拿港口，北岸机场还能起降。
   这解释了 C4 为什么值得单独分兵，也解释了灰原为什么不直接在西线追击到底。

### 【补】为什么是 1207 年秋

- 雾岭冬季封山（`docs/01:370-379`）。灰原从北面南下，重装备与补给要走边陲公路
  和青溪仅有的两处渡口（`docs/01:21`）。封山前不打开突破口，入冬就得停下。
- C1 简报「九月二号他们过河，六号打到北岭山下，三天，四十公里」
  （`campaign.html:1304`）——三天四十公里是在抢这个窗口。
- 秋季规则机动 0、侦察 +1（`docs/01:376`），是全年最适合进攻的季节。

**没采用的两个方向**（都超出本轮"不新增势力与地名"）：

| 方向 | 不用的理由 |
|---|---|
| 灰原缺某项资源所以南下 | 要新增资源设定，且与"资源型联邦"重复；把借口坐实成动机，反而削弱"边境事故"这层伪装 |
| 内部政变 / 预防性战争 | 要新增政治实体与人物，且第 8 章终局还没有政治设定可挂 |

## 二、翻盘：不是我方变强，是敌方优势失效

### 事实

| 事实 | 出处 |
|---|---|
| 苍屿常备军有限、重装备依赖进口 | `docs/01:7` |
| 1–3 章一路退到首都圈；C12「那是全战役最后一次增援」 | `docs/01:176-240`、`campaign.html:5438` |
| C4 港内分舰队：4 艘驱逐舰、2 艘巡洋舰、1 艘战列舰，**不出港，炮口对着岸上**，射程 8–20 格 | `campaign.html:2552-2553` |
| 具名舰（战列舰「北岭」、驱逐舰「坚忍」、巡洋舰「波尔瓦萨」）全属我方；敌方全篇无舰船 | `docs/24` |
| 冬季：机动 −1、侦察 −1、空中出动 −1、补给消耗 −1 | `docs/01:370-379` |
| 第 5 章有潮汐湾登陆、长湾海峡突破（唯一一次纯海战）；C5 有第 21 空降军伞兵 | `docs/01:259-272`、`docs/24` |
| C3B 撑到「最后一批运输机起飞」；第 6 章有「机场再开」 | `campaign.html:2228,2337`、`docs/01:282` |
| 运输机联队在兵种表里本来就有 | `campaign.html:650` |

### 【补】一句话

**苍屿没有突然变强，是灰原那套陆军优势的适用条件一个个消失了。**
三个支点都是已经写好的东西，不是新设定：

1. **战略目标始终没兑现。** 灰原要的是能用的前进航空基地。C3B 最后一批运输机起飞后，
   苍屿主动放弃岚口；直到第 6 章「机场再开」才重新启用。中间一年多，机场始终是
   一块不能用的跑道——把仗打到人家首都，最想要的那个东西一直没拿到。
   > 这条要靠第 3–4 章里一句"机场没能启用"才站得住，否则只是本文的推论。见 §四第 7 行。
2. **冬季封山钉住的是进攻方。** 规则对双方一视同仁，但第 3 章标题「一步不退」已经给了答案：
   机动归零之后，守方只要不退就达标，进攻方必须重新打开节奏。冬季不是给我方加东西，
   是把"推进"这件事本身变贵了——所以第 3 章是相持章，不是反攻章。
3. **制海权一直在苍屿手里。** C4 那支分舰队"不出港"是被当成岸防炮台用
   （射程覆盖全场），不是打没了。敌方全篇没有舰船。到第 5 章，同一支舰队从"炮口对着岸上"
   改成"出港"，才有潮汐湾登陆与海峡突破。**第 5 章的两栖能力不是新装备，是既有海军换了用法**；
   C5 的空投伞兵同理。

### 与八章曲线对齐

| 章 | 敌方优势状态 | 曲线 |
|---|---|---|
| 1–2 | 摩步炮兵协同、推进快，拿到土地但没拿到机场 | 下行 |
| 3 | 冬季封山，推进成本骤升 | 走平 |
| 4 | 「近卫装甲第 2 师不可战胜」被打破——优势的心理面先塌 | 拐点 |
| 5 | 制海权转为进攻，海峡通道重新打开 | 上行 |
| 6–8 | 补给线拉到最长，逐点被收回 | 上行 |

**不引入外援，是硬约束不是偏好**：C12 已经写死「全战役最后一次增援，之后再也没有了」。
再加第三方会直接和这句冲突，而且本轮不新增势力。

## 三、终局：停战线，不是灭国

### 事实

| 事实 | 出处 |
|---|---|
| 灰原是「**联合体**」 | `docs/01:10` |
| 第 8 章「城下之盟」是全篇唯一以"不打"为最优解的一关，靠兵力态势逼对方签字 | `docs/01:310,317` |
| 附属关「停战线」；第 4 关「灰原首都」；第 5 关「胜利日」 | `docs/01:305-315` |
| 写作边界：不映射任何现实国家或地区 | `docs/01:381-383` |

### 【补】

- 终局条件回到开战目标：**灰原放弃对长湾海峡通道的主张**。
  所以「城下之盟」才是结构上的终点，「灰原首都」只是把逼签的筹码做出来，
  「胜利日」是对停战线的确认，不是灭国。开战与终局因此扣成同一个环。
- 「联合体」自带多成员结构：战败后能签字、也值得签，不需要再设定一个政府或和谈代表。
- **一处落笔时要留意的顺序问题**：章节表里「城下之盟」是第 2 关、「灰原首都」是第 4 关，
  如果写成"打进首都才逼签"，顺序会读反。要么把第 2 关理解成停战条件先成形、
  筹码后到位，要么调整两关的功能定位。本文只指出，不替你定。

**替代方向**：想要更硬的结局（解体 / 长期占领）需要新增政治设定与章节，
既超出本轮范围，也撞上"不新增势力"的约束。
