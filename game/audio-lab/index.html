怎么定：听完告诉我每组选哪个字母，比如「fire 要 B，其余按你标的」。 也可以直接说哪里不对——太轻 / 太闷 / 太电子 / 太长 / 声音太干净缺战场噪，我按方向再找。
关于"真实"：fire 的 A/B/C 是实弹录音（96kHz 采样，枪口冲击波和混响都是真的），D 是影视素材。 shell / kill 目前没有找到真实火炮实录——维基共享资源、archive.org、SoundBible 在国内全部连不上， 只能用影视拟音，听感上"像"，但不是真炮。这一条我没法糊弄过去。
