音效 A/B 对照

左列是上一版，右列是现在游戏里用的。同一行就是同一个槽位，点一下挨着听。
rifle / step / track / engine 四行已换成 freesound 实录，左列因此是上一版合成；
prop / ship / airgun / bomb 四行是新开的槽——它们的左列是这几族原来借用的东西 （卡车的引擎声、地面的步枪声、地面的炮声），读作"拆开之前 / 拆开之后"，
shell 行比较特殊——左右是同一段录音里的两发不同的炮，听的差别来自源，不是处理。
其余行仍是左列现用、右列未被采用的合成候选。
先说清楚哪些不该换。 fire 这一行你会明显听出来：现有素材是 .22 实弹录音，起振 0.2 ms， 合成版是 0.3 ms——这 0.1 ms 就是"真枪"和"音效"的分界，代码补不上。 能用合成赢的只有一种情况：现有素材的方向就不对（比如 event 现在是个通用提示音， 而你的设定里那份情报是电报来的）。

战场底噪 · 60 秒无缝循环
合成底噪之上垫了四发远处炮火（第 6.2 / 15.1 / 31.4 / 44.7 秒，四档不同距离）， 用的是你选的那条「大炮」——它 2 kHz 以上只占 0.04，近听是闷，远处听正好， 因为高频在空气里衰减最快。四发在 60–200 Hz 上高出底噪 14–17 dB：不是"听清"，是"感到"。

怎么听才有效。 同一个槽位连着点三下，先旧的再三下新的，比来回切更准——来回切的时候，第二声总是显得"更好"， 因为耳朵在找变化。
底噪要开着 BGM 听。它单独听是一团噪音，判断不了；跟 battle.ogg 一起放才知道有没有打架—— 两者都在 20–90 Hz 有能量，这是我按 vol.sfx 0.65 / vol.bgm 0.35 换算后定到 −31 dBFS RMS 的原因。
