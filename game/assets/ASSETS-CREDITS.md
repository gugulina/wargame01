## 二、为什么这四栏必须填满

1. **授权凭证**：项目用了 7 个 CC-BY 音效，靠 `CREDITS.md` 逐条署名才站得住。图片现在登记为"本作 / AI 生成 + 手工微调 / 随本作"——这是**可商用**的写法，但前提是所用模型的条款允许商用（见第三节）。
2. **可追溯**：两年后要重绘同一角色，得知道当初用的什么模型、什么提示词、修了哪里。
3. **仓库是公开的**：GitHub Pages 上每张图都能被单独下载。

## 三、AI 出图需要补的一句

「AI 生成 + 手工微调」在授权上还要回答一个问题：**生成时用的模型/服务，条款是否允许商用与再分发**。

- 允许商用的（如各家付费版、Apache-2.0 许可的开源权重）：填上模型名与版本即可，许可证写「随本作」。
- 条款含糊或禁止商用的：这两张图要重出。

建议在下面补一行（我无法替你确认当时用的是哪个）：

```
模型：<名称 + 版本>　出图日期：<YYYY-MM>　微调内容：<线稿 / 配色 / 修手 / 背景>
```

`ASSETS.ui` / `unit` / `fort` 的空槽见 `docs/09-封版评估.md` 与 [`待补素材.md`](待补素材.md)。

## 五、规格（新增图按这个来）

- **立绘**：480×640（3:4），webp q80–85，深色描边会糊，别压太狠；显示尺寸 132×176。
- **背景板**：1600×900 或 1200×800，webp q80。
- **图标**：64×64 透明底 PNG/WebP，键名与 `TYPE` 对齐。

## 六、防复发

`tools/briefcheck.js` 有一条断言：**`ASSETS.story` 里每个非 null 的文件，都必须在这份台账里被点名**。
加新图忘了登记 → `npm test` 变红。这条不检查"填得对不对"（那只能人看），只管"有没有这一行"。
