# 素材待补清单（采购规格单）

这份是给"自己找素材"用的。每个槽位写清楚**要多长、要多短、听感要什么方向、什么格式**，
找的时候按这个筛，回来只管丢文件。

找完把文件放进对应目录，我改 `ASSETS` 一行就接上，游戏逻辑不用动。
通用规范在最后一节，**尤其注意命名和授权两条**。

## 一、音效：21 个槽位（已有一套能用的，可逐个替换）

现在这套的问题你已经听出来了：军事类那五个（fire / shell / hit / kill / alarm）是实弹录音
和影视拟音，听感上还是"电影里的枪炮"。要找的是纪录片/实拍那种。

> **2026-10-26：已有一批合成版，不必等素材站。**
> `tools/sfx-synth.js` 用纯 DSP 合成，`npm run sfx` 出 `*-synth.ogg`（7 个：
> shell / fire / build / event / alarm / move / amb），**不覆盖现有文件**。
> 试听页 `game/audio-lab/sfx-demo.html` 是逐槽位 A/B 对照。
>
> 结论先说：**fire 别换**。现有素材是 .22 实弹录音、起振 0.2 ms，合成版实测 0.86 ms——
> 那 0.66 ms 就是"真枪"和"音效"的分界，代码补不上。
> 合成真正赢的是**方向本来就不对**的那几个：`event`（现有是通用提示音，设定里那份情报是电报来的）、
> `alarm`（现有是电子警报，二战阵地是手摇转轮）、`build`（现有是通用打击音，听不出在挖什么）。

### 时长是硬指标，比音色更容易翻车

上一版翻车的直接原因不是音源差，是**选长了**：machinegun 3.16s、small_explosion1 2.14s，
一回合打三枪，三个 3 秒音效叠起来就是一堵噪音墙。下表"上限"这一列是硬约束。

| 槽位 | 什么时候响 | 现在时长 | **上限** | 听感要求 |
|---|---|---|---|---|
| `fire` | 步兵/装甲直射开火，**一回合可能响 3–5 次** | 0.63s | **0.8s** | 单发步枪/机枪点射。要听见枪口冲击的"啪"，不要"biu"。带一点场地回响可以，不能带长尾 |
| `shell` | 炮兵射击。同时只允许响 1 个 | 2.43s | **3.0s** | 炮弹出膛或落点爆炸。要有低频冲击**和**爆裂，光闷不脆就是闷雷。允许长尾 |
| `hit` | 命中结算，**高频重复** | 0.21s | **0.35s** | 极短促的击打/小爆炸。宁可短，长了连续命中会糊成一片 |
| `kill` | 兵牌被歼灭 | 1.65s | **2.5s** | 有份量的爆炸，多爆点（弹药殉爆感）比单响好 |
| `alarm` | 敌方增援投入战场 | 1.83s | **2.5s** | 警报/号声。**不要导弹发射音**（上一版就错在这） |
| `build` | 构筑工事 / 布雷 / 架桥 | 0.94s | **1.2s** | 挖掘、夯土、金属敲击。工程感，不要爆炸 |
| `event` | 战役事件触发 | 0.54s（合成版已接入） | **0.6s** | 电报/提示音。中性，不要战斗音 |
| `uiClick` | 按钮 | 0.10s | **0.15s** | 干脆的咔哒 |
| `select` | 选中兵牌 | 0.05s | **0.12s** | 比 uiClick 更轻，别抢 |
| `move` | 兵牌移动 | 0.18s（合成版已接入） | **0.20s** | 闷响/履带摩擦，轻 |
| `amb` | 战场全程（循环） | 60.0s（合成版已接入） | **60s 整** | 远处炮声、零星枪声、风。垫层，不许有可辨识旋律 |
| `win` | 达成战役目标 | 0.91s | **2.0s** | 短乐句，收得干净 |
| `lose` | 战役失败 | 0.94s | **2.0s** | 下行短乐句，不要悲情过度 |

### 战场底噪（已接入）

**战场底噪**：远处的持续炮声、零星枪声、风。以前一次攻击只响一声，中间全静音，不像战场。

**2026-10-26：已实装。** 槽位 `amb`，文件 `amb-take1.ogg`，60 秒无缝循环、450 KB、RMS −31 dBFS。

- **不进 preload**：`FX._noPreload.amb = true`。这类"60 秒循环层"一旦跟着首屏走，
  首屏就从 186 KB 涨到 636 KB，且不报错。`briefcheck [23]` 守这一条。
- **预载本身也按关收窄了**（v4.12）：`sfxForLevel()` 只拉本关编制用得上的槽，
  纯步兵关 186 KB / 有空军的 222 KB / 港口战 264 KB，全量上限仍是 300 KB。
- **独立音量 `vol.amb = 0.60`**：文件本身已经比 BGM 低 5.6 dB，不需要再压；
  这个键留着，等音量设置面板（A1）做出来时接上去。
- **起停是幂等的**：`FX.amb(true/false)` 随时调，重复调没有代价。挂在
  进关（起）、结算（淡出 0.8s）、进指挥部（淡出）、出指挥部（接回，
  但已分胜负就不接）、以及首次手势的 `resumeAmb()` 上。
- **淡入 1.4s / 淡出 0.8s**：循环噪声轨从静音直接跳满，听感是"啪一下世界被打开了"，
  和一次性音效的包络不是一回事。

### 下载渠道（这几个国内能直连，2026-10 实测）

| 站点 | 授权 | 备注 |
|---|---|---|
| **opengameart.org** | 多为 CC0 / CC-BY | **必须带 UA 头，否则 403**。枪声类真实录音最多，搜 `gunshot` |
| **mixkit.co**（Envato） | 明确允许游戏，免署名 | 影视拟音，不是现场实录。禁单独再分发素材本身 |
| **kenney.nl** | 全站 CC0 | UI 音效与短乐句的主力，直接下 zip |
| **freesound.org** | 逐个看（CC0 / CC-BY / CC-BY-NC） | 下载要登录，响应慢。**注意 NC 的不能商用** |

连不上的：Wikimedia Commons、archive.org、soundbible（超时）；pixabay（反爬 403，浏览器能开，只能手动下）。

**真正要找实拍炮声，最靠得住的是 Freesound 上搜 `artillery` / `cannon fire` 筛 CC0。**
它慢、要登录，但那是唯一有大量现场录音的地方。

## 二、背景音乐：4 首（0/4，全空）

| 槽位 | 用途 | 时长 | 风格 |
|---|---|---|---|
| `menu` | 开始页（还没有） | 1–2 分钟循环 | 低沉、克制，不要激昂 |
| `battle` | 战斗主循环 | 2–3 分钟循环 | 进行感，不抢注意力，**能听 20 分钟不烦** |
| `tension` | 关键时刻（机场告急等） | 1–2 分钟循环 | 压迫、节拍渐紧 |
| `result` | 结算画面 | 1–2 分钟 | 胜/败共用一条即可，靠画面区分 |

**两个前置问题：**

1. **没有开始页，放 BGM 也是静音。** 浏览器要求用户先有交互动作才能播音频。
   所以顺序是：先做开始页 → 再放音乐。
2. **体积。** 单曲 1–3 MB，四首就是 4–12 MB，仓库会明显变胖。建议 ogg 96kbps 或 mp3 128kbps，
   一首压到 800KB–1.5MB。

授权：Mixkit Music（同 SFX 授权，允许游戏）、Incompetech（CC-BY，**必须署名**）。
注意 CC-BY 意味着游戏里得有个署名页——目前没有。

## 三、图片：24 + 12 + 5 + 5 个槽（全空）

**这一批有一个前置条件，不做就接不上：棋盘分层渲染。**

现在 `renderBoard()` 每帧用 `innerHTML` 重建全部 280 个格子。纯 CSS 画格子没问题，
换成 `<img>` 之后图片会反复重建、闪烁、手机掉帧。**必须先拆成"静态地形层 + 动态兵牌层"。**

所以顺序是：**先做分层渲染 → 再放图片**。这一批暂时别找，找了也接不上。

### 3.1 兵种图标（21 个）

键名与 `TYPE` 表一一对应，**加兵种必须补槽，自测会校验**。建议 64×64 透明底 PNG/WebP。

```
inf 步兵   gdn 近卫   mob 摩托   mech 摩托化   arm 装甲
art 火炮   hr  火箭炮  sha 自行炮  spa 自行高炮  at  反坦克
eng 工兵   engc 工兵连 rec 侦察   sup 补给     avn 陆航
aac 高炮   aab 高炮营  hqd 师部   hqb 旅部     hkg 团部  hkc 军部
```

风格上建议**单色剪影 + 兵种符号**（北约式），不要写实小图——280 格里写实图会糊成一团。

### 3.2 地形贴图（12 个）

`hexPlain hexForest hexHill hexTown hexAir hexFord hexRoad hexRiver` 八个六角格，
再加 `icCity icAirport icTown icFord` 四个要点徽标。**96×110，与格子同比例**。

### 3.3 工事图标（5 个）

`H` 堑壕 / `B` 碉堡 / `P` 要塞炮 / `A` 岸防炮 / `F` 防空阵地。建议 28×28，
与现在格内的字母角标**二选一**（有图标就不显示字母）。

### 3.4 剧情（5 个）

`bgBriefing bgVictory bgDefeat` 三张背景（1600×900，16:9）
+ `portBlue portRed portHQ` 三张剧情位。

**立绘的两个尺寸是分开的，别混：**

| 项 | 数值 |
|---|---|
| 立绘位成显尺寸 | **132×176**（CSS px，竖半身 3:4） |
| **要交的源图** | **480×640**（精确 3:4） |
| 格式 / 体积 | WebP 或 PNG 透明底，单张 < 80 KB |
| 顶部安全边距 | 画布高度的 8%（约 51px），别让头发顶边 |

比例必须精确 3:4 —— 立绘位是 `background-size: cover`，比例不对会上下对称裁切，
**头顶是最先被切掉的**。480×640 是 3.64 倍图，够手机 DPR 3（需求 396×528）还有余量。

| 槽位 | 画什么 | 能不能不画 |
|---|---|---|
| `portBlue` | 我方旅长（岚口预备役第 1 旅，半身） | 缺了显示"立绘位"占位字 |
| `portRed` | 敌方摩步第 3 旅前沿（半身） | 同上 |
| `portHQ` | **符号位，不是人物** | **可以不填**，缺省自动画电台符号 |

`portHQ` 对应「方面军司令部 · 电话」那句——那是"听来的声音"，没有人物出场，
塞一张人脸反而出戏。放个听筒/电台符号更对。想画也行，填了就会盖住符号。

### 3.5 尺寸对照速查

| 槽位 | 成显（CSS px） | 交稿（px） | 倍率 | 状态 |
|---|---|---|---|---|
| 六角格贴图 | 47×54 | 96×110 | 2.04× | 未实装（卡在分层渲染） |
| 剧情立绘 | **132×176** | **480×640** | **3.64×** | **已实装，可直接接** |
| 剧情背景 | 全屏 | 1600×900 | — | 逻辑已实装 |
| 兵种图标 | 兵牌是 30×26，图标得缩到 22 以内 | 64×64 | — | 未实装 |
| 工事图标 | 未定 | 28×28 | — | 未实装 |

## 四、通用规范（放文件之前先看这四条）

### 1. 命名：全小写 ASCII + 连字符

`Cannon.PNG` 这种**本地能跑、线上 404**。Windows 文件系统不分大小写，GitHub Pages 的 Linux 分。
中文文件名同理，别用。

### 2. 格式

- 音频：**mp3 单声道 112kbps 或 ogg，采样率 44.1kHz**
  - 不要降到 22.05kHz。实测 `fire` 起振会从 1.5ms 被抹成 2.9ms，枪声变"噗"
  - mp3 的编码延迟不会拖钝瞬态（实测过，1.5ms→1.5ms），可以放心压
- 图片：PNG（要透明）或 WebP。单张控制在 50KB 以内

### 3. 改内容必须改文件名

替换 `fire-v2.mp3` 时请叫 `fire-v3.mp3`，然后在 `ASSETS` 里改路径。
同名覆盖的话浏览器会读缓存，**本地听着"没变化"，能查半天**。这个坑踩过一次。

### 4. 授权：只收能商用的

| 授权 | 能不能用 | 要注意 |
|---|---|---|
| **CC0 / 公有领域** | 最好 | 随便用，不用署名 |
| **CC-BY** | 能用 | **必须署名**。游戏至今没有署名页，要用就得先加 |
| **CC-BY-NC** | **不能** | NC = 非商用。以后想收个赞助就违约 |
| 站点自订条款 | 逐条看 | Mixkit / Kenney 这种明确允许游戏的可以 |
| "仅供个人学习" | **不能** | 最常见也最容易忽略 |

到时候要么全部重找，要么带着风险发布。
